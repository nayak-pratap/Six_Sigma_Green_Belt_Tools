# Six Sigma Green Belt Toolkit

Interactive calculators and tools for Six Sigma Green Belt projects. Each page opens with worked example values from one running case (chipped carbide inserts), recalculates as you type, and has a **Reset to example values** button. Everything runs in the browser: no build step, no server, no data leaves the page.

## Calculators

| Page | What it does |
|---|---|
| [Sigma Level and DPMO Calculator](calculators/sigma-dpmo.html) | Turn defect counts into DPU, DPMO, yield and sigma level, with or without the 1.5σ shift. |
| [Process Capability Calculator (Cp, Cpk)](calculators/process-capability.html) | Compare your process spread and centring with the specification limits and estimate parts per million out of spec. |
| [Control Chart Limits Calculator](calculators/control-limits.html) | Centre line and 3σ limits for X-bar and R, I-MR, p, np and c charts, with the constants shown. |
| [Two-Sample t-Test (Welch)](calculators/two-sample-t-test.html) | Test whether two process means differ, from summary statistics, with p-value and 95% confidence interval. |
| [Gage R&R Calculator](calculators/gage-rr.html) | Judge a measurement system from its repeatability, reproducibility and part-to-part variation. |
| [FMEA Risk Priority Board](calculators/fmea-board.html) | Score failure modes for severity, occurrence and detection, see the RPN and sort by risk. |
| [Lean Flow Calculators](calculators/lean-flow.html) | Takt time, Little’s law, process cycle efficiency and rolled throughput yield in one place. |

## Run it

Open `index.html` in a browser. To publish with GitHub Pages: repository **Settings, Pages, Build and deployment, Deploy from a branch, main, / (root)**. The site then appears at `https://<your-user>.github.io/SixSigma_GreenBelt_Tools/`.

## Structure

```
index.html            landing page
calculators/          one self-contained page per calculator
tools/                one self-contained page per tool
assets/style.css      shared styles (light and dark themes)
assets/lib.js         shared statistics and page helpers
```

## Method notes

- Normal CDF, inverse normal, t and incomplete-beta functions are implemented in `assets/lib.js` and were checked against known values.
- Sigma level uses the conventional 1.5σ shift (switchable in the DPMO calculator).
- Control chart constants cover subgroup sizes 2 to 10.
- Worked examples are invented for illustration. Check your own data, standards and customer requirements before acting on a result.
