Calculators and tools for DMAIC projects

Every page opens with worked example values from one running case (chipped carbide inserts), recalculates as you type, and has a button to return to the examples. Nothing is sent anywhere: all calculation happens in your browser.

Where these tools lead

DMAIC Project Workbook →

One project carried from charter to closure on a single dataset, with each stage computing from the stage before it. It runs at Black Belt depth — regression, a designed experiment, Gage R&R by ANOVA — so it is worth reading for the shape of a whole project even before you need those methods.
