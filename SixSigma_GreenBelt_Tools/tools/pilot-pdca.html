Pilot and PDCA Decision Tool

Compare pilot results with the baseline, check them against the success criterion and get an adopt, adapt or abandon recommendation.

Plan the pilot, run it small, then check the result with a proper test, not by eye. Example: a finer hone media tried on 8 lots. “Lower is better” here because the measure is a defect rate.
