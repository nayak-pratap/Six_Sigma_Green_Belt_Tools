Fault Tree Analysis

Build a fault tree from basic events and AND/OR gates, compute the probability of the top event and see which fix reduces it most.

Row 1 is the top event. A gate row lists the IDs of the events below it. A basic event row has a probability for the period you care about (for example per lot). Events are assumed independent. Example: why an insert is chipped at final inspection.

All calculators and toolsWorked examples are illustrative. Check your own data, standards and customer requirements before acting on a result.
